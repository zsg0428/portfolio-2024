# Dempsey Zhang, portfolio

Live at https://dempsey-portfolio.vercel.app

Next.js App Router, TypeScript and Tailwind CSS. Every fact on the page lives in
`src/content/site.ts`, so updating the site after a resume change means editing one file.

```bash
pnpm install
pnpm dev
pnpm typecheck && pnpm lint && pnpm build
```
